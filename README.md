# Sevic Reach

Sevic Reach is a dedicated sales operating system, pipeline management, and outreach automation platform.

## Features

- **Pipeline & Stage Management**: Kanban board and list views with custom filtering, stage cadences, and follow-up tracking.
- **Multi-channel Outreach**: Automated email and WhatsApp messaging with personalisation templates and sequence schedules.
- **Enrichment & Research**: AI-assisted lead research, fit scoring, and brief generation.
- **Campaigns**: Multi-step automated outreach campaigns with reply detection and stop logic.
- **Analytics & Funnel Reporting**: Real-time conversion metrics across every sales stage.

## Development

Prerequisites: Node.js (v20+) and npm.

```sh
# Install dependencies
npm install

# Start local development server
npm run dev

# Run test suite
npm test

# Build for production
npm run build
```
